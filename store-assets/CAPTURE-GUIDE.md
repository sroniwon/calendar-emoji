# 실제 캡처 가이드 (Real Screenshot Guide)

목업 이미지(`screenshot-1.png`)는 빠른 출시용으로 사용 가능하지만, **실제 Google Calendar 화면에서 익스텐션이 동작하는 모습**을 캡처하면 더 신뢰감 있고 승인 확률도 높아집니다. 이 가이드는 그걸 5분 안에 끝내는 방법입니다.

---

## 0. 준비물

- Chrome 브라우저 (개발자 모드에서 익스텐션 설치)
- 캡처 도구: 윈도우는 `Win + Shift + S`, 맥은 `Cmd + Shift + 4`
- 더미 Google 계정 또는 임시 캘린더 (개인정보 노출 방지)

---

## 1. 익스텐션 설치 (개발 모드)

1. `chrome://extensions` 접속
2. 우상단 **개발자 모드** ON
3. **압축 해제된 확장 프로그램 로드** → `extension/` 폴더 선택
4. 익스텐션이 활성화되고 툴바에 아이콘이 보이는지 확인

---

## 3. 캡처 사이즈 가이드

Chrome Web Store에서 요구하는 사이즈는 다음 중 하나입니다:

| 용도 | 크기 | 권장 |
|---|---|---|
| 메인 스크린샷 | **1280 × 800** | ✅ 권장 (고해상도) |
| 메인 스크린샷 | 640 × 400 | 작은 화면용 |
| 프로모션 타일 (Small) | **440 × 280** | ✅ 필수 |
| 프로모션 타일 (Marquee) | 1400 × 560 | 옵션 (피쳐드 신청용) |

### Chrome 브라우저를 정확한 사이즈로 조절하기

DevTools를 활용하면 픽셀 단위로 정확하게 잡을 수 있어요:

1. Chrome에서 `F12` (DevTools 열기)
2. 좌상단 **장치 툴바 토글** 아이콘 클릭 (또는 `Ctrl + Shift + M`)
3. 상단 사이즈 입력란에 **1280 × 800** 직접 입력
4. 우측 점 3개 메뉴 → **Capture screenshot**

이 방법이 가장 정확합니다. 캡처가 자동으로 정확한 픽셀 크기로 저장됩니다.

### 또는 정직하게 캡처:

윈도우 `Snipping Tool` / 맥 `Cmd+Shift+4` 로 자유 영역 캡처 후, 이미지 편집기로 1280x800으로 크롭/리사이즈.

## 5. 캡처 후 체크리스트

- [ ] **개인 정보 노출 없음** (이름, 이메일, 실제 약속 내용 등)
- [ ] **정확한 사이즈** (1280×800 또는 640×400)
- [ ] **PNG 포맷** (JPG 가능하지만 PNG가 더 선명)
- [ ] **5MB 이하** 파일 크기
- [ ] **글자가 읽힐 정도로 선명** (블러/저해상도 X)
- [ ] **익스텐션 기능이 명확히 보임** (이모지 적용된 일정이 화면에 있음)
- [ ] **브랜드 일관성** (가능하면 같은 테마/색감)

---

## 6. 프로모션 타일 (440 × 280)

`promo-tile.png`가 이미 만들어져 있습니다. 이대로 사용해도 되고, Canva/Figma에서 약간 수정해도 됩니다.

권장 요소:
- 익스텐션 이름 (Calendar Emoji Auto-Tagger)
- 핵심 가치 한 문장 ("이모지를 자동으로 추가")
- 시각적 임팩트 (캘린더 아이콘 + 이모지)
- 브랜드 색감 일관성 (#2F6B3F 녹색 + #F7C85C 노란색)

---

## 7. 업로드 순서 팁

Chrome Web Store에 업로드할 때, **첫 번째 스크린샷이 제일 크게 노출됩니다.** 그래서 가장 임팩트 있는 장면 (Screenshot 1: 캘린더 + 팝업 동시 노출)을 1번에 두세요.
